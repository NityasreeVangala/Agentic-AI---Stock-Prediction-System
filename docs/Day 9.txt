## **Step 1: Understanding Candlestick Charts (30 min)**

1. **What is a Candlestick Chart?**

   * Visual representation of stock **OHLC data**:

     * **O**pen: price at start of period
     * **H**igh: highest price
     * **L**ow: lowest price
     * **C**lose: price at end of period
   * Each “candlestick” represents **1 day** (or other time period).

2. **Why Candlestick?**

   * Shows **trend, volatility, and reversals** at a glance.
   * Used by traders and platforms like **TradingView**.

3. **Colors:**

   * **Green candle:** Close > Open → price increased
   * **Red candle:** Close < Open → price decreased

4. **Data needed:**

   * Your CSV already has **Date, Open, High, Low, Close, Volume**.

import pandas as pd

def get_stock_history(symbol: str):
    df = pd.read_csv(f"data/{symbol}.csv")
    df['Date'] = pd.to_datetime(df['Date'])

## **Step 4: Create Candlestick Component in React (90 min)**

### **File: `frontend/src/components/CandlestickChart.jsx`**

```jsx
import React, { useEffect, useState } from "react";
import axios from "axios";
import {
  ResponsiveContainer,
  ComposedChart,
  XAxis,
  YAxis,
  Tooltip,
  Bar,
  Line,
} from "recharts";

const CandlestickChart = ({ symbol }) => {
  const [data, setData] = useState([]);

  useEffect(() => {
    const fetchHistory = async () => {
      if (!symbol) return;
      try {
        const res = await axios.get(`http://127.0.0.1:8000/history/${symbol}`);
        setData(res.data.history);
      } catch (err) {
        console.error(err);
      }
    };
    fetchHistory();
  }, [symbol]);

  if (!data.length) return <p>Loading chart...</p>;

  // Transform data for Recharts candlestick-like bar
  const chartData = data.map((d) => ({
    date: new Date(d.Date).toLocaleDateString(),
    open: d.Open,
    close: d.Close,
    high: d.High,
    low: d.Low,
    color: d.Close > d.Open ? "#4caf50" : "#f44336", // green/red
  }));

  return (
    <ResponsiveContainer width="100%" height={400}>
      <ComposedChart data={chartData}>
        <XAxis dataKey="date" hide />
        <YAxis domain={['dataMin', 'dataMax']} />
        <Tooltip />
        {chartData.map((d, i) => (
          <Bar
            key={i}
            dataKey="close"
            fill={d.color}
            barSize={4}
            yAxisId={0}
          />
        ))}
      </ComposedChart>
    </ResponsiveContainer>
  );
};

export default CandlestickChart;
```

---

### **Explanation for Beginners**

1. **State + API call:**

   * `useEffect` fetches historical data from backend when `symbol` changes.
2. **Data transformation:**

   * Converts `Date` to readable string
   * Sets `color` green/red depending on price movement.
3. **Recharts ComposedChart:**

   * `XAxis` → dates (hidden for cleaner look)
   * `YAxis` → price scale
   * `Bar` → shows candles (simplified, can refine later)
   * `Tooltip` → shows OHLC on hover
4. **ResponsiveContainer:**

   * Makes chart adjust to screen width

> ⚠️ Note: Recharts doesn’t have native candlestick, but this **simulates it for beginners**. Later you can switch to `lightweight-charts` for exact candlestick visuals.
