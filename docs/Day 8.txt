# **DAY 8 – API → Frontend Integration & Debounced Search (4h)**

**Goal:**

Make the **frontend search box** fully interactive by **calling your backend `/search` API** and showing suggestions in **real time**. Add **debouncing** so that the API isn’t called on every keystroke — this prevents unnecessary network requests and makes the search smooth.

---

## **Step 1: Understanding the Concept (30 min)**

1. **API → Frontend Integration:**

   * Your backend exposes `/search?q=...` (e.g., `/search?q=rel`) which returns matching stock symbols as JSON.
   * Frontend **calls this API** whenever the user types in the search box.

2. **Debouncing:**

   * Without it: Every keystroke triggers a request → slows down UX → too many requests.
   * With it: Wait a small delay (e.g., 300ms) after typing stops, then send the request.
   * Helps **reduce server load** and improve **user experience**.

3. **Expected Output:**

   * Typing “re” shows `[“RELIANCE”]` after a short pause.
   * Typing “t” shows `[“TCS”]`.
   * Smooth dropdown suggestions without flickering.

## **Step 3: Create Debounced Search Function (60 min)**

### File: `frontend/src/components/SearchBox.jsx`

```jsx
import React, { useState, useEffect } from "react";
import axios from "axios";

// Debounce helper function
function debounce(func, delay) {
  let timeout;
  return function (...args) {
    if (timeout) clearTimeout(timeout);
    timeout = setTimeout(() => {
      func.apply(this, args);
    }, delay);
  };
}

const SearchBox = ({ onSelectStock }) => {
  const [query, setQuery] = useState("");          // what user types
  const [results, setResults] = useState([]);      // API results
  const [loading, setLoading] = useState(false);   // loading state

  // Function to call backend API
  const fetchResults = async (q) => {
    if (!q) {
      setResults([]);
      return;
    }
    setLoading(true);
    try {
      const res = await axios.get(`http://127.0.0.1:8000/search?q=${q}`);
      setResults(res.data.results);  // array of stocks
    } catch (err) {
      console.error("API error:", err);
    }
    setLoading(false);
  };

  // Debounced version of fetchResults (300ms delay)
  const debouncedFetch = debounce(fetchResults, 300);

  // Call debounced function whenever query changes
  useEffect(() => {
    debouncedFetch(query);
  }, [query]);

  return (
    <div className="relative w-80">
      <input
        type="text"
        className="w-full border p-2 rounded"
        placeholder="Search stock..."
        value={query}
        onChange={(e) => setQuery(e.target.value)}
      />
      {loading && <div className="absolute right-2 top-2 text-gray-500">Loading...</div>}

      {results.length > 0 && (
        <ul className="absolute w-full border mt-1 bg-white shadow rounded z-10 max-h-40 overflow-y-auto">
          {results.map((stock) => (
            <li
              key={stock}
              className="p-2 hover:bg-gray-200 cursor-pointer"
              onClick={() => {
                onSelectStock(stock); // notify parent component
                setQuery(stock);       // fill input with selected stock
                setResults([]);        // hide dropdown
              }}
            >
              {stock}
            </li>
          ))}
        </ul>
      )}
    </div>
  );
};

export default SearchBox;
```

---

### **Explanation for Beginners**

1. **State Variables:**

   * `query`: current input value.
   * `results`: list of stock suggestions.
   * `loading`: shows a tiny “loading…” indicator.

2. **Debounce Function:**

   * Uses `setTimeout` to **wait 300ms** after last keystroke before calling the API.
   * `clearTimeout` cancels previous pending calls.

3. **API Call:**

   * `axios.get` → calls your FastAPI endpoint (`/search?q=...`)
   * Sets `results` state to display in dropdown.

4. **Dropdown Rendering:**

   * Maps through `results` array.
   * Each item is **clickable** → selects stock and fills input box.

5. **Parent Component Communication:**

   * `onSelectStock(stock)` notifies **App.jsx** which stock was selected.

## **Step 4: Connect to Parent Component (15 min)**

### File: `frontend/src/App.jsx`

```jsx
import React, { useState } from "react";
import SearchBox from "./components/SearchBox";

function App() {
  const [selectedStock, setSelectedStock] = useState(null);

  return (
    <div className="p-4">
      <h1 className="text-2xl font-bold mb-4">Agentic Stock AI</h1>
      <SearchBox onSelectStock={setSelectedStock} />

      {selectedStock && (

          <h2 className="text-xl font-semibold">Selected Stock: {selectedStock}</h2>
          <p>Next steps: display charts, indicators, predictions...</p>
        </div>
      )}
    </div>
  );
}

export default App;
```

**Explanation:**

* `setSelectedStock` updates state when user clicks a stock in the dropdown.
* Displays **currently selected stock**.

## **Step 6: Tips for Beginners**

* **Why debounce?** Prevents your backend from being flooded if user types “reliance” quickly.
* **Why `z-10` on dropdown?** Ensures dropdown appears **above other elements**.
* **Why `useEffect` with `query` dependency?** So API is called **whenever input changes**, not randomly.
* **Why `setResults([])` on click?** Hides dropdown after selection → clean UX.
