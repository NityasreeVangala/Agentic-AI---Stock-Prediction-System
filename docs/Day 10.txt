# **Day 10 (4 hours) – Snapshot Logic**

## **Objective**

We want to implement a **snapshot system** for stock prices.

> Think of it like taking a **photo of the stock market** on a specific day. This “photo” will freeze the prices at that moment so our system always has a **consistent reference point** for calculations, reporting, and predictions.

For this day, we are **freezing the last known price as of 31-12-2025**.

This is important because stock prices **change every day**, and if we don’t freeze them, any analysis, comparison, or prediction we make could **change unpredictably**.

---

## **Step 1 – Understand the Problem**

1. We have stock data stored in CSV files or a database, e.g., **RELIANCE.NS, TCS.NS, etc.**
2. We want to **capture a snapshot of all stock prices** on a **specific date** (31-12-2025).
3. Later, when the user queries the system or runs analysis, the system should always refer to **this frozen snapshot** instead of live or continuously changing data.

---

## **Step 2 – Why Freeze a Snapshot?**

* **Consistency:** All calculations (like predictions, RSI, trend analysis) should use the same reference price.
* **Auditability:** We can always see what the system used at a certain point in time.
* **Debugging:** If something goes wrong, we can compare results against the snapshot.
* **Time-Safe Analysis:** Avoids using “future data” in historical simulations or predictions.

---

## **Step 3 – Define the Snapshot**

A snapshot contains **all essential information about each stock on a given day**:

| Field  | Description                                  |
| ------ | -------------------------------------------- |
| Symbol | Stock ticker (e.g., RELIANCE.NS, TCS.NS)     |
| Date   | Snapshot date – in this case, **31-12-2025** |
| Open   | Opening price of the stock on that day       |
| High   | Highest price reached during that day        |
| Low    | Lowest price reached during that day         |
| Close  | Closing price of the stock                   |
| Volume | Number of shares traded                      |

**Note:** You can extend this table with derived indicators like RSI, MACD, trend, etc., but the snapshot should always have the **raw base values**.

## **Step 2 – Snapshot Logic (Python)**

Create a new file:

**`backend/app/services/snapshot_service.py`**

```python
import pandas as pd
from pathlib import Path

# List of stocks
STOCKS = ["RELIANCE.NS", "TCS.NS", "HDFCBANK.NS", "INFY.NS", "YESBANK.NS"]

# Path to data folder
DATA_DIR = Path(__file__).parent.parent / "data"

# Snapshot date
SNAPSHOT_DATE = pd.Timestamp("2025-12-31")

# Path to save snapshot
SNAPSHOT_FILE = DATA_DIR / "snapshot_2025-12-31_all.csv"


def create_snapshot():
    """
    Reads all stock CSVs, filters data for snapshot date,
    and saves a combined snapshot CSV.
    """
    all_snapshots = []

    for stock in STOCKS:
        csv_file = DATA_DIR / f"{stock}.csv"
        df = pd.read_csv(csv_file)
        df['Date'] = pd.to_datetime(df['Date'])
        snapshot_row = df[df['Date'] == SNAPSHOT_DATE].copy()
        snapshot_row['Symbol'] = stock  # add stock symbol
        all_snapshots.append(snapshot_row)

    # Combine all stocks
    final_snapshot = pd.concat(all_snapshots, ignore_index=True)

    # Save snapshot CSV
    final_snapshot.to_csv(SNAPSHOT_FILE, index=False)
    print(f"Snapshot saved: {SNAPSHOT_FILE}")


def get_snapshot():
    """
    Reads the snapshot CSV and returns a list of dictionaries
    """
    if not SNAPSHOT_FILE.exists():
        create_snapshot()  # create snapshot if missing

    df = pd.read_csv(SNAPSHOT_FILE)
    df['Date'] = pd.to_datetime(df['Date'])
    return df.to_dict(orient="records")
```

## **Day 10 – Snapshot Logic (4h)**

**Goal:**
We want a **time-safe system** that takes the latest stock prices from your historical CSV and “freezes” them on **31-12-2025**. Later, this snapshot will be used for predictions, analysis, or dashboard display.

### **Step 1: Create snapshot service**

Inside your backend:

```
backend/app/services/

```
snapshot_service.py

Paste this code:

```python
import pandas as pd
import os

# Path to the merged stock CSV
ALL_STOCKS_PATH = os.path.join(os.path.dirname(__file__), "../data/all_stock_prices.csv")
SNAPSHOT_OUTPUT_PATH = os.path.join(os.path.dirname(__file__), "../data/snapshot_2025-12-31_all.csv")

def generate_snapshot(snapshot_date="2025-12-31"):
    """
    Generates a snapshot of all stocks for the given date.
    Only keeps the last known price per stock on or before snapshot_date.
    """
    # Load merged historical data
    if not os.path.exists(ALL_STOCKS_PATH):
        raise FileNotFoundError(f"Historical data CSV not found at {ALL_STOCKS_PATH}")

    df = pd.read_csv(ALL_STOCKS_PATH, parse_dates=["Date"])

    # Filter data to only keep the last known price per stock on or before snapshot_date
    df = df[df['Date'] <= snapshot_date]

    if df.empty:
        print("No data available before the snapshot date!")
        return pd.DataFrame()  # return empty dataframe if nothing found

    # Get the last known price for each stock
    snapshot_df = df.sort_values("Date").groupby("Symbol").tail(1)

    # Save snapshot CSV
    snapshot_df.to_csv(SNAPSHOT_OUTPUT_PATH, index=False)
    print(f"✅ Snapshot saved at {SNAPSHOT_OUTPUT_PATH}")
    print(snapshot_df)
    return snapshot_df
```

**Explanation (beginner-friendly):**

1. We read the **merged CSV** of all 5 stocks.
2. Filter all rows **before or on 31-12-2025**.
3. For each stock, pick the **last available row** → this is the “frozen” price.
4. Save the snapshot to a new CSV:

```
snapshot_2025-12-31_all.csv
```

This CSV now contains exactly **one row per stock** with the last known price.
