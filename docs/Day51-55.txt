## 🔹 **Day 51–53: Ensemble Predictions & Weighted Averaging**

### **Goal:**

Combine predictions from multiple models (XGBoost + LSTM) to get a more robust forecast.

### **Why?**

* Each model has strengths and weaknesses:

  * **XGBoost** → Good at capturing short-term trends, handles tabular features like lagged prices and moving averages.
  * **LSTM** → Good at sequential patterns, long-term dependencies.
* By **combining them**, you reduce the risk of relying on one model that may overfit or underfit.

---

### **Step-by-step explanation:**

1. **Fetch model predictions**

   * Assume we have predictions for the next N days:

     ```python
     XGB_pred = [1500, 1505, 1510, ...]  # XGBoost predictions
     LSTM_pred = [1498, 1507, 1509, ...] # LSTM predictions
     actual_prices = [1495, 1502, 1508, ...] # For evaluation
     ```

2. **Decide weights for each model**

   * Example: If XGBoost is slightly more accurate historically:

     ```python
     weight_xgb = 0.6
     weight_lstm = 0.4
     ```
   * These weights can also be tuned based on **validation RMSE or MAE**.

3. **Compute ensemble prediction using weighted average**

   * Formula:
     [
     ensemble_pred[i] = XGB_pred[i] * weight_xgb + LSTM_pred[i] * weight_lstm
     ]
   * Example in Python:

     ```python
     ensemble_pred = [
         x*weight_xgb + y*weight_lstm
         for x, y in zip(XGB_pred, LSTM_pred)
     ]
     ```

4. **Visualize**

   * Plot actual vs XGB vs LSTM vs Ensemble predictions using **Recharts** or **Matplotlib**:

     * This helps see if the ensemble smooths out errors.

---

### ✅ Key Takeaways:

* Ensemble predictions are **more stable**.
* Weighted averaging allows us to **trust the better model more**.
* Can also extend later to more models (e.g., Prophet, ARIMA).

## 🔹 **Day 55: Backtesting**

### **Goal:**

Validate how your models would have performed **historically**.

---

### **Step-by-step explanation:**

1. **Why backtest?**

   * You cannot blindly trust predictions.
   * Backtesting simulates how your models would have predicted **past data** using only **information available at that time**.

2. **Split historical data into rolling windows**

   * Example:

     ```python
     train_window = 200  # last 200 days to train
     test_window = 20    # next 20 days to test
     ```
   * Move the window forward and **retrain + predict** each step.

3. **Compare predictions to actual prices**

   * Metrics to check:

     * RMSE (Root Mean Squared Error)
     * MAE (Mean Absolute Error)

     ```python
     from sklearn.metrics import mean_squared_error, mean_absolute_error
     rmse = mean_squared_error(actual, predicted, squared=False)
     mae = mean_absolute_error(actual, predicted)
     print(f"RMSE: {rmse:.2f}, MAE: {mae:.2f}")
     ```

4. **Visualize backtest results**

   * Plot actual vs predicted for each rolling window.
   * Helps identify **periods where model struggles** (e.g., high volatility).

5. **Refine ensemble weights or models**

   * If XGB underperforms in volatile months → reduce its weight in ensemble.
   * Backtesting is **iterative** → helps improve **robustness**.
