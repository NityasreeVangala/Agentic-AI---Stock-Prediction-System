# 🔹 PART 1 (0:00–0:45)

## What Is a Backend? (Beginner Explanation)

### ❌ Beginner misconception

> “Backend is just Python code that does ML.”

### ✅ Reality

Backend is:

> The **brain + control center** of your application.

It:

* Receives requests from frontend
* Fetches data
* Runs logic
* Returns structured responses (JSON)

---

### Simple analogy

Frontend = restaurant menu
Backend = kitchen

User clicks “Search TCS” →
Backend:

1. Understands request
2. Fetches data
3. Processes logic
4. Sends response back

---

### Why backend comes before ML

If backend is messy:

* You cannot scale
* You cannot debug
* You cannot integrate frontend

So today we **only care about structure**, not intelligence.

# 🔹 PART 4 (2:30–3:30)

## FastAPI Basics (Slow & Clear)

### Step 1: Install FastAPI

Create `requirements.txt` inside `backend/`:

```text
fastapi
uvicorn
```

Install:

```bash
pip install -r requirements.txt
```

---

### Step 2: Write `main.py`

Open `backend/app/main.py`:

```python
from fastapi import FastAPI

app = FastAPI(
    title="Agentic Stock AI",
    description="Multi-model stock analysis system",
    version="0.1.0"
)

@app.get("/")
def root():
    return {"message": "Stock AI backend is running"}
```

---

### What is happening here?

* `FastAPI()` → creates backend app
* `@app.get("/")` → URL endpoint
* Function returns JSON

---

### Step 3: Run the server

From `backend/` folder:

```bash
uvicorn app.main:app --reload
```

---

### Expected output in browser

Go to:

```
http://127.0.0.1:8000
```

You should see:

```json
{
  "message": "Stock AI backend is running"
}
```

🎉 **Your backend is alive.**

# 🔹 PART 5 (3:30–4:30)

## Add a Health Check Endpoint (Professional Practice)

Add this to `main.py`:

```python
@app.get("/health")
def health():
    return {
        "status": "ok",
        "service": "stock-ai-backend"
    }
```

---

### Why this matters

* Frontend can check backend health
* DevOps best practice
* Used in production monitoring

---

### Test it

Go to:

```
http://127.0.0.1:8000/health
```
