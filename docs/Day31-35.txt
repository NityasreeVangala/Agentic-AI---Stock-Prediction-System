# 🟦 DAY 31 — What Is Time-Series Forecasting?

### 1️⃣ What is time-series data?

Time-series = data ordered by **time**

Example (you already have this):

| Date       | Close |
| ---------- | ----- |
| 2024-01-01 | 2400  |
| 2024-01-02 | 2420  |
| 2024-01-03 | 2415  |

Key property:

> **Tomorrow depends on yesterday**

This is why normal ML models don’t work well here.

---

### 2️⃣ Why we don’t start with deep learning

Beginners often jump to LSTM — **bad idea**.

Why?

* Hard to debug
* Needs tons of data
* Hard to explain

💡 **Industry rule**:

> Always start with **simple statistical models**

So we start with:

* ARIMA (math-based)
* Prophet (trend-based)

# 🟦 DAY 32 — ARIMA (Baseline Model)

### 1️⃣ What is ARIMA (intuitively)?

ARIMA asks:

> “Given recent past values, what comes next?”

It does **NOT** know:

* News
* Fundamentals
* Indicators

It ONLY knows:
📈 Past prices

---

### 2️⃣ ARIMA has 3 parts (simple explanation)

**ARIMA(p, d, q)**

| Letter | Meaning         | Simple explanation              |
| ------ | --------------- | ------------------------------- |
| AR     | Auto-Regression | Tomorrow depends on past days   |
| I      | Integrated      | Remove trend (make data stable) |
| MA     | Moving Average  | Smooth noise                    |

You **do NOT** tune this manually at first.

---

### 3️⃣ Why ARIMA is important

* Gives a **baseline forecast**
* If advanced models don’t beat ARIMA → they’re useless

Think of ARIMA as:

> “Common sense mathematical prediction”

---

### 4️⃣ What ARIMA will output

Example:

| Date   | Predicted Close |
| ------ | --------------- |
| Day +1 | 2450            |
| Day +2 | 2462            |
| Day +3 | 2470            |

# 🟦 DAY 33 — Prophet (Trend-Aware Model)

### 1️⃣ What is Prophet?

Prophet is built by **Facebook (Meta)**.

It assumes:

> Price = **Trend + Seasonality + Noise**

---

### 2️⃣ Why Prophet is beginner-friendly

Unlike ARIMA:

* Automatically detects trends
* Handles missing data
* Easy to visualize
* Extremely stable

Perfect for:

* Stock prices
* Business metrics
* Growth curves

---

### 3️⃣ Prophet components (very important)

| Component   | Meaning                     |
| ----------- | --------------------------- |
| Trend       | Long-term growth or decline |
| Seasonality | Weekly / yearly patterns    |
| Noise       | Random movement             |

Stocks usually have:

* Weak seasonality
* Strong trend

---

### 4️⃣ Prophet forecast output

| Date       | yhat (prediction) | yhat_lower | yhat_upper |
| ---------- | ----------------- | ---------- | ---------- |
| 2025-01-01 | 2450              | 2400       | 2500       |

This gives **confidence intervals** 🔥
(ARIMA does not do this cleanly)

# 🟦 DAY 34 — Forecast Horizon (1M, 3M, 6M, 12M)

### 1️⃣ What is forecast horizon?

How far into the future you predict.

Common choices:

* 30 days (1 month)
* 90 days (3 months)
* 180 days (6 months)
* 365 days (12 months)

---

### 2️⃣ Industry truth (important)

The further you predict:

* ❌ Accuracy drops
* ❌ Noise increases

So we **never trust a single number**.

Instead:

* Use **trend direction**
* Use **percentage change**

---

### 3️⃣ What your agent should extract

Not:

> “Price will be 2478”

But:

* Expected direction: UP / DOWN
* Expected return: +8%
* Risk range: ±10%

This is what investors care about.
