# 🟩 DAY 4 — WHAT WAS CREATED (EXACTLY)

## 🎯 Goal of Day 4

> “Fetch, clean, align, and VERIFY real market data.”

---

## 📁 1. `backend/app/services/data_fetcher.py`

**Purpose:** Download and clean raw stock data

### Core responsibilities:

* Fetch NSE / BSE historical prices
* Restrict dates (2010 → 2025)
* Clean columns
* Ensure timezone correctness

📌 Contains functions like:

```python
fetch_stock_data(symbol)
clean_stock_data(df)
```

This file is **pure data logic** — no API, no ML.

---

## 📁 2. `backend/app/services/market_merger.py`

**Purpose:** Align NSE & BSE data

### Core responsibilities:

* Merge datasets by date
* Prefer NSE when available
* Fall back to BSE if NSE missing
* Output a single `Close_Final` column

📌 This is where **financial realism** happens.

---

## 📁 3. `backend/tests/test_data_fetch.py`

**Purpose:** Manual verification script

This file:

* Fetches NSE + BSE data
* Cleans it
* Merges it
* Prints:

  * Row counts
  * Sample data
  * Last trading date

📌 This file is **NOT production code**
It is **human verification code**.

---

## 📁 4. `docs/day4_data_validation.md`

**Purpose:** Audit trail

Contains:

* Symbols tested
* NSE rows
* BSE rows
* Merged rows
* Last trading date
* Observations

📌 This is how real funds stay compliant.
