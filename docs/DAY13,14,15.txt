## ### Day 13 – Rank metrics & convert to layman language

**Goal:**
We have normalized fundamentals for all stocks (PE, EPS, ROE, Debt). Now, we want to **rank these metrics** and make them understandable in plain language.

**Step 1: Rank metrics**

* **Idea:** We want to know which stock is **best/worst for each metric**.
* For each metric (PE, EPS, ROE, Debt):

  1. Sort all stocks by the metric.
  2. Assign a **rank**:

     * Highest value → rank 1 (best)
     * Lowest value → rank 5 (worst)

Example using your normalized fundamentals:

| Stock       | PE   | EPS | ROE | Debt |
| ----------- | ---- | --- | --- | ---- |
| TCS.NS      | 0.87 | 1   | 0.7 | 0.09 |
| RELIANCE.NS | 0.67 | 0.7 | 1   | 0.27 |
| HDFCBANK.NS | 0.47 | 0.8 | 0.6 | 0.18 |
| YESBANK.NS  | 0    | 0   | 0   | 1    |
| INFY.NS     | 1    | 0.9 | 0.8 | 0    |

**Ranking Example (PE):**

* INFY.NS = 1 → rank 1 (best)
* TCS.NS = 0.87 → rank 2
* RELIANCE.NS = 0.67 → rank 3
* HDFCBANK.NS = 0.47 → rank 4
* YESBANK.NS = 0 → rank 5 (worst)

> Do this for each metric separately.

---

**Step 2: Convert to layman language**

* Investors don’t want to see raw numbers, they want **plain English statements**.
* Example rules:

| Metric | High value | Low value | Example phrase                                                  |
| ------ | ---------- | --------- | --------------------------------------------------------------- |
| PE     | High       | Low       | “Stock is expensive” / “Stock is cheap”                         |
| EPS    | High       | Low       | “Company earns a lot per share” / “Earnings are low”            |
| ROE    | High       | Low       | “Company generates good returns on equity” / “Returns are weak” |
| Debt   | High       | Low       | “High debt risk” / “Low debt, financially safe”                 |

* Now, instead of numbers, you can say something like:

> “TCS.NS has high earnings (EPS), moderate PE, good ROE, and very low debt – overall healthy stock.”

```python
# backend/app/services/fundamentals.py
from app.data.fundamentals_data import fundamentals  # we will store normalized values here

def rank_metrics():
    """
    Rank each stock's metrics (PE, EPS, ROE, Debt)
    Returns a dictionary with ranks.
    """
    metrics = ["PE", "EPS", "ROE", "Debt"]
    stocks = list(fundamentals.keys())
    
    ranked = {stock: {} for stock in stocks}
    
    for metric in metrics:
        # Sort stocks by metric
        # For Debt, lower is better → reverse=True for others, False for Debt
        reverse = metric != "Debt"
        sorted_stocks = sorted(stocks, key=lambda s: fundamentals[s][metric], reverse=reverse)
        
        # Assign ranks (1=best, 5=worst)
        for rank, stock in enumerate(sorted_stocks, start=1):
            ranked[stock][metric] = rank
            
    return ranked

def layman_insights(stock):
    """
    Convert normalized fundamentals to plain English insights
    """
    data = fundamentals[stock]
    insights = {}
    
    # PE
    if data["PE"] > 0.8:
        insights["PE"] = "PE is high, stock is slightly expensive"
    elif data["PE"] < 0.3:
        insights["PE"] = "PE is low, stock is cheap"
    else:
        insights["PE"] = "PE is moderate"

    # EPS
    if data["EPS"] > 0.8:
        insights["EPS"] = "Earnings per share are high"
    elif data["EPS"] < 0.3:
        insights["EPS"] = "Earnings per share are low"
    else:
        insights["EPS"] = "Earnings per share are moderate"

    # ROE
    if data["ROE"] > 0.8:
        insights["ROE"] = "Generates excellent returns for shareholders"
    elif data["ROE"] < 0.3:
        insights["ROE"] = "Returns are weak"
    else:
        insights["ROE"] = "Returns are decent"

    # Debt
    if data["Debt"] < 0.3:
        insights["Debt"] = "Low debt, financially safe"
    elif data["Debt"] > 0.7:
        insights["Debt"] = "High debt, risky"
    else:
        insights["Debt"] = "Moderate debt"

    return insights

def top5_positives_risks(stock):
    """
    Returns top 5 positives and top 5 risks for a stock
    """
    data = fundamentals[stock]
    positives = []
    risks = []

    # Simple scoring: >0.7 is positive, <0.3 is risk
    for metric, value in data.items():
        if metric == "PE":  # for PE, lower is better
            if value < 0.3:
                positives.append("PE is low, stock is cheap")
            elif value > 0.7:
                risks.append("PE is high, stock may be expensive")
        elif metric == "EPS":
            if value > 0.7:
                positives.append("High earnings per share")
            elif value < 0.3:
                risks.append("Low earnings per share")
        elif metric == "ROE":
            if value > 0.7:
                positives.append("Generates excellent returns")
            elif value < 0.3:
                risks.append("Low return on equity")
        elif metric == "Debt":
            if value < 0.3:
                positives.append("Low debt, financially safe")
            elif value > 0.7:
                risks.append("High debt, risky")
    
    # Keep only top 5 (if fewer, that's fine)
    return {"positives": positives[:5], "risks": risks[:5]}
```
