## 🕒 Step 3 – Create SearchBox.jsx

**File:** `frontend/src/components/SearchBox.jsx`

**Content:**

```jsx
import React, { useState } from "react";
import axios from "axios";

const SearchBox = ({ onSelect }) => {
  const [query, setQuery] = useState("");
  const [results, setResults] = useState([]);

  const handleChange = async (e) => {
    const value = e.target.value;
    setQuery(value);

    if (!value) {
      setResults([]);
      return;
    }

    try {
      const res = await axios.get(`http://127.0.0.1:8000/search?q=${value}`);
      setResults(res.data.results);
    } catch (err) {
      console.error(err);
    }
  };

  return (
    <div>
      <input
        type="text"
        value={query}
        onChange={handleChange}
        placeholder="Search stock..."
        className="border p-2 rounded w-full"
      />
      <ul className="border mt-1 rounded max-h-40 overflow-y-auto">
        {results.map((item) => (
          <li
            key={item}
            onClick={() => onSelect(item)}
            className="p-2 hover:bg-gray-200 cursor-pointer"
          >
            {item}
          </li>
        ))}
      </ul>
    </div>
  );
};

export default SearchBox;
```

**What we did:**

1. `useState` stores **typed query** and **results**
2. `handleChange` → called on every keystroke

   * Calls `/search?q=...` API
   * Updates results dynamically
3. Renders `<input>` + `<ul>` for **autocomplete dropdown**
4. Click on suggestion calls `onSelect`

**Output:** Typing in the box fetches suggestions from backend

## 🕓 Step 4 – Integrate SearchBox in App.jsx

**File:** `frontend/src/App.jsx`

```jsx
import React, { useState } from "react";
import SearchBox from "./components/SearchBox";

function App() {
  const [selectedStock, setSelectedStock] = useState("");

  return (
    <div className="max-w-md mx-auto mt-10">
      <h1 className="text-2xl font-bold mb-4">Agentic Stock AI</h1>
      <SearchBox onSelect={setSelectedStock} />
      {selectedStock && (
        <p className="mt-4">You selected: {selectedStock}</p>
      )}
    </div>
  );
}

export default App;
```

**Explanation:**

* `selectedStock` stores which stock was clicked
* `setSelectedStock` passed as `onSelect` to `SearchBox`
* Updates display below search box

**Output:** User clicks a suggestion → selected stock is displayed

## 🕔 Step 5 – Backend CORS Fix

**File:** `backend/app/main.py`

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],  # frontend URL
    allow_methods=["*"],
    allow_headers=["*"],
)
```

**Why:**

* Frontend runs on `5173`, backend on `8000` → cross-origin request blocked by browser
* CORS middleware allows frontend to fetch `/search`
