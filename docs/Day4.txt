```python
import yfinance as yf
import pandas as pd
from datetime import datetime

START_DATE = "2010-01-01"
END_DATE = "2025-12-31"

def fetch_stock_data(symbol: str) -> pd.DataFrame:
    """
    Fetch historical stock data from Yahoo Finance.
    """
    stock = yf.Ticker(symbol)
    df = stock.history(start=START_DATE, end=END_DATE)

    # Ensure Date is a column
    df.reset_index(inplace=True)

    return df
```

---

### What this code is doing (SLOW EXPLANATION)

* `yf.Ticker(symbol)` → connects to data source
* `.history()` → downloads historical prices
* `reset_index()` → turns date index into a column

## Handling Missing Dates (VERY IMPORTANT)

### ❌ Beginner mistake

> “Let me fill missing dates with last price.”

This creates **fake data**.

---

### Why dates are missing

* Weekends
* Holidays
* No trading occurred

Missing dates ≠ missing information.

---

### Correct approach

* **Accept missing dates**
* Do NOT forward-fill blindly
* Use business-day logic only when needed

---

### Add basic sanity checks

Update `data_fetcher.py`:

```python
def clean_stock_data(df: pd.DataFrame) -> pd.DataFrame:
    """
    Basic cleaning: sort data and remove empty rows.
    """
    df = df.sort_values("Date")
    df = df.dropna(subset=["Close"])
    return df
```

### Why this is enough for now

* We’re not training models yet

### Code (Beginner Friendly)

```python
import pandas as pd

def merge_nse_bse(nse_df: pd.DataFrame, bse_df: pd.DataFrame) -> pd.DataFrame:
    """
    Merge NSE and BSE data, preferring NSE prices.
    """

    nse_df["Exchange"] = "NSE"
    bse_df["Exchange"] = "BSE"

    merged = pd.merge(
        nse_df,
        bse_df,
        on="Date",
        how="outer",
        suffixes=("_nse", "_bse")
    )

    merged["Close_Final"] = merged["Close_nse"].combine_first(
        merged["Close_bse"]
    )

    final_df = merged[["Date", "Close_Final"]].sort_values("Date")

    return final_df
```

---

### What this achieves

* One price per day
* NSE preferred
* No cheating
* No hallucinated values

# 🔴 WHY IT IS STILL FAILING (ROOT CAUSE)

Python still cannot see `app` because:

👉 **`backend/` itself is NOT a Python package yet**

Python only treats folders as packages if:

* They are on `sys.path`
* OR they contain `__init__.py`
* OR you explicitly add them to `PYTHONPATH`

Right now:

```

├── app/        ← package
│   ├── __init__.py
├── tests/
```

But **`backend/` itself is invisible** to Python.
