## **DAY 1 – Understanding Stock Prediction & LLMs (4h)**

**Goal:** Build a clear mental model of **stock prediction** before touching code.

**Tasks:**

1. **Understand the difference between LLM & predictor**

   * LLM (like ChatGPT) can explain stock trends, do research, but **cannot predict prices accurately**
   * Real stock prediction uses **time series forecasting**, **technical indicators**, **fundamentals**, etc.

2. **Study Time Series Basics**

   * Features: OHLCV → Open, High, Low, Close, Volume
   * Patterns: Trend, Seasonality, Noise

3. **Learn pitfalls**

   * Overfitting → model memorizes past data, fails on unseen data
   * Lookahead bias → using future information for past predictions

**Output:**

* Mental clarity on why we need **historical stock data** + **technical indicators**
* No code or files created on Day 1

## **DAY 6 – Autocomplete Search API (4h)**

**Goal:** Backend **prefix search** API for stock symbols

**Tasks:**

1. Implement `search_stocks()` in `services/search_service.py`:

```python
STOCKS = ["TCS", "RELIANCE", "HDFCBANK", "YESBANK", "INFY"]

def search_stocks(query: str):
    query = query.upper()
    return [s for s in STOCKS if s.startswith(query)]
```

2. Add **FastAPI endpoint** in `main.py`:

```python
from fastapi import Query

@app.get("/search")
def autocomplete(q: str = Query(..., min_length=1, max_length=10)):
    results = search_stocks(q)
    return {"query": q, "results": results}
```

3. Add **CORS** for frontend (`5173`):

```python
from fastapi.middleware.cors import CORSMiddleware
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_methods=["*"],
    allow_headers=["*"],
)
```

**Output:**

* `/search?q=rel` returns `["RELIANCE"]`
* Backend ready for React frontend
