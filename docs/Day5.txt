# 🕑 Step 2 — Create a `data_saver.py` utility

File: `backend/app/services/data_saver.py`

**Purpose:** Save any merged DataFrame to a CSV automatically.

Code:

```python
import os

def save_to_csv(df, symbol):
    # Make 'data/' folder if missing
    os.makedirs("data", exist_ok=True)
    
    # File path
    file_path = f"data/{symbol}.csv"
    
    # Save CSV (overwrite if exists)
    df.to_csv(file_path, index=False)
    
    print(f"[INFO] Saved {symbol} data to {file_path}")
```

**Why this is important:**

* Automates saving
* Handles folder creation
* Ensures filename matches symbol

# 🕒 Step 3 — Create `save_data_to_csv.py` test script

File: `backend/tests/save_data_to_csv.py`

**Purpose:** Loop through all 5 stocks, fetch, clean, merge, and save CSV.

Code:

```python
from app.services.data_fetcher import fetch_stock_data, clean_stock_data
from app.services.market_merger import merge_nse_bse
from app.services.data_saver import save_to_csv

# List of 5 stocks
symbols = ["TCS.NS", "RELIANCE.NS", "HDFCBANK.NS", "YESBANK.NS", "INFY.NS"]

for sym in symbols:
    # Fetch data
    nse = fetch_stock_data(sym)
    bse = fetch_stock_data(sym.replace(".NS", ".BO"))
    
    # Clean data
    nse_clean = clean_stock_data(nse)
    bse_clean = clean_stock_data(bse)
    
    # Merge NSE + BSE
    merged = merge_nse_bse(nse_clean, bse_clean)
    
    # Save CSV
    save_to_csv(merged, sym.replace(".NS",""))
```

**Key points:**

* Handles NSE + BSE automatically
* Saves in a standardized CSV format
* Prints confirmation for each stock
